How It Works

Get your server running in minutes with three simple steps

1

Download & Install

Grab the MSI or EXE installer for Windows, or the APK for Android. Run the installer and launch Portal Host.

2

Create Your Server

Click "Create Server", pick a name, choose your Minecraft version (Paper, Fabric, Forge, Vanilla, and more), and configure settings.

3

Start & Play

Hit Start, wait for the server to launch, then connect using the address shown. Invite friends and enjoy!
