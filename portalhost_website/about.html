About Portal Host

Your Ultimate Minecraft Server Manager

What is Portal Host?

Portal Host is a free, open-source desktop application designed to make managing Minecraft Java Edition servers simple and intuitive. Whether you're hosting a private world for friends, running a community server, or testing plugins and mods, Portal Host handles the complexity so you can focus on playing.

Built with modern technologies including Kotlin Multiplatform and Compose Multiplatform, Portal Host provides a native-feeling experience on Windows with a clean, dark-themed interface that matches the aesthetic of the game itself.

Key Features

  • Server Creation & Management — Create new servers with custom names, select Minecraft versions, and configure basic settings through a guided setup process.
  • Real-Time Console Access — View live server output, enter commands, and monitor server health without leaving the application.
  • Player Administration — Ban, kick, whitelist, op/de-op players, and manage permissions through an intuitive interface.
  • Automatic JDK Management — Portal Host automatically detects, downloads, and configures the correct Java version for each Minecraft release.
  • Multi-Version Support — Run multiple servers on different Minecraft versions simultaneously.
  • System Tray Integration — Minimize to tray, keep servers running in the background, and access quick actions from the menu bar.

Getting Started

1

Download & Install

Download the latest MSI or EXE installer from the Download page and run it

2

Launch Portal Host

Open the app from your Start Menu or desktop shortcut

3

Create Your First Server

Click "Create Server", choose a name, select a Minecraft version, and hit Create

4

Start & Play

Click Start on your new server, wait for it to launch, then connect using the displayed address

System Requirements

  • OS: Windows 10/11 (64-bit)
  • RAM: 4 GB minimum (8 GB+ recommended)
  • Storage: 2 GB+ free space
  • Java: Automatically managed by Portal Host

Technology Stack

Portal Host is built with modern, cross-platform technologies:

  • Kotlin Multiplatform — Shared business logic
  • Compose Multiplatform — Declarative UI
  • Koin — Dependency injection
  • Ktor — HTTP client
  • SQLite — Local storage
  • WiX Toolset — Windows installer

Open Source

Portal Host is completely open source under the MIT License. The source code, issue tracker, and releases are all available on GitHub.
